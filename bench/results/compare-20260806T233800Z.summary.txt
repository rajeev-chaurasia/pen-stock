How to read the delta columns
------------------------------------------------------------------------------
mean : the mean delta IS the mean per request overhead. Means subtract
       exactly, so E[gateway] - E[direct] = E[overhead], even though no
       request was ever measured both ways.

p50/p95/p99 : DIFFERENCES OF QUANTILES, not quantiles of the per request
       overhead. Quantiles do not subtract. The p95 row says how far each
       gateway moved the 95th percentile of end to end latency, which is a
       fair statement about the tail of the system. It does NOT say 95% of
       requests paid less than that. Nothing here can say that, because
       measuring one request both with and without a gateway at the same
       time is not possible.

Comparing the two delta columns to each other is the only comparison this
run supports, and only for the one workload it sent: a single non
streaming chat completion to one model on one provider. LiteLLM does far
more than that. See docs/comparison.md.
